ホーム/Remote MCP Server
REMOTE MCP SERVER 運用中

AIエージェントから、
そのまま使えるWebサイトへ。

SPACE GLEAM株式会社は、自社コーポレートサイトで Remote MCP（Model Context Protocol）Server を本番実装・運用しています。ChatGPT・Claude・Cursor などの外部AIエージェントから、サービス検索・AI開発診断・相談要件の整理を直接実行できます。

ENDPOINT
https://spacegleam.co.jp/api/mcp
TRANSPORT
Streamable HTTP（JSON-RPC 2.0 / POST・GET）
PROTOCOL
2025-03-26
OPENAPI
https://spacegleam.co.jp/openapi.json
LLMS.TXT
https://spacegleam.co.jp/llms.txt

HOW TO USE

使い方

お使いのAIクライアントに接続先を登録するだけで利用できます。アカウント登録や認証キーは不要です。

01

クライアントに接続先を登録する

Claude や Cursor など、リモートMCP（Streamable HTTP）に対応したクライアントでは、設定ファイルに次の1件を追加します。

{ "mcpServers": { "spacegleam": { "url": "https://spacegleam.co.jp/api/mcp" } } }
リモート接続に未対応のクライアントの場合
{ "mcpServers": { "spacegleam": { "command": "npx", "args": ["-y", "mcp-remote", "https://spacegleam.co.jp/api/mcp"] } } }
02

つながっているか確かめる

クライアントを使わずに、コマンドラインから直接確認することもできます。サーバー情報が返れば接続できています。

curl -X POST https://spacegleam.co.jp/api/mcp \ -H "Content-Type: application/json" \ -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
03

そのまま話しかける

接続後は、AIが文脈に応じてツールを呼び出します。特別なコマンドを覚える必要はありません。

  • SPACE GLEAMに業務自動化を頼むと、費用と期間はどれくらい？
  • 予算100万円で社内の問い合わせ対応をAI化したい。診断して。
  • ここまでの相談内容を、依頼用の要件メモにまとめて。

02 のコマンドは、このページの公開時点で実際に応答することを確認しています。接続できない場合は、クライアントがリモートMCP（Streamable HTTP）に対応しているかをご確認ください。

TOOLS

公開しているMCPツール

AIエージェントが会話の文脈に応じて呼び出せる5つのツールを公開しています。

search_services

AI開発・SaaS開発・業務自動化・MCP開発などから、相談内容に近い領域を検索します。

run_diagnosis

事業課題や予算をもとに、概算費用・推奨プラン・開発期間・想定リスクを診断します。

generate_project_brief

会話の内容から、相談用の構造化されたプロジェクト概要メモを生成します。

create_lead

利用者の明示的な同意を確認したうえで、問い合わせを送信します。

get_company_profile

会社概要、強み、対応領域、コンプライアンス情報を取得します。

SECURITY

無断送信を防ぐ設計

閲覧・診断系のツール（読み取り操作）は公開されており、自由にお試しいただけます。一方、送信をともなう操作には制限を設けています。

同意の確認
問い合わせ送信ツール create_lead は、利用者の明示的な同意（consentConfirmed: true）がなければ実行されません。
入力値の検証
送信前に厳格なバリデーションを行います。
レート制限
IP単位のレート制限を適用しています。

診断を実行しただけでメールが届くことはありません。送信は、利用者が明示的に同意した場合にのみ行われます。

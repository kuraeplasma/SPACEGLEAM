自社で開発・運用しているプロダクト

御御御付 具材認識AI味噌汁診断

冷蔵庫の具材をスマホで撮るだけで、食材を認識し、今日作れる味噌汁のレシピと栄養情報を自動提案するサービス。

クリックで拡大

開発の背景

「冷蔵庫にある食材を使い切りたい」「今日の栄養バランスを考えたい」という日常の課題を解決するために開発。

スマホで写真を1枚撮るだけで食材を自動認識し、最適な味噌汁のレシピからカロリーや塩分などの栄養情報までを瞬時に提案する仕組みです。

気分や体調に合わせた「診断」機能や、好きな具材を自由に組み合わせる「ビルダー」機能も搭載しています。

主な機能

写真から食材自動認識味噌汁レシピ自動生成栄養バランス・カロリー計算気分や体調に合わせた診断お気に入り保存機能

公開可能な構成

Next.js / TypeScript
画像認識AI (Vision API / Gemini API)
栄養データベース設計
レスポンシブWebデザイン (TailwindCSS)

開発範囲

具材自動認識とレシピ生成を実装
LP、診断、ビルダー、お気に入り、および画像解析API連携まで対応

現在の状況
